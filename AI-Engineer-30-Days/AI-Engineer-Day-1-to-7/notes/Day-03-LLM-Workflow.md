# Day 3 — LLM Workflow and Core Concepts

This note summarises a typical workflow used in an LLM-powered application.

## Typical LLM application flow
1. A user enters a question or task.
2. The application prepares the prompt and relevant context.
3. The application sends the request to a model, directly or through an API.
4. The model generates a response.
5. The application displays or processes the response.

## Important terms
- **Model:** The trained system that processes input and generates output.
- **Prompt:** The instruction or input given to the model.
- **Context:** Information available to the model for the current task.
- **Inference:** Running the trained model to produce output.
- **Output:** The response generated by the model.

## Example
A user asks, “Explain recursion in Java.” The app sends that request with an instruction such as “Explain simply and include an example.” The model generates an explanation, and the app displays it.

## Responsible use
Check important answers, avoid sending secrets or unnecessary personal data, and use human verification when the stakes are high.
