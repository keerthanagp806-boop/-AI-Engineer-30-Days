# Day 4 — Revision and Foundations

Use this day to connect AI, ML, DL, and LLM concepts.

## Concept map
- AI is the broad field of intelligent computer systems.
- ML learns patterns from data.
- DL uses multi-layer neural networks.
- LLMs are deep-learning models designed for language tasks.
- Inference is when a trained model is used to respond to new input.

## Example: AI study chatbot
1. The user types a question.
2. The application prepares the question as model input.
3. A language model processes the input.
4. The model generates text.
5. The application displays the answer.
