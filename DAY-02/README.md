6. Limitations and considerations.

## Key takeaways
- An LLM is a model trained on large amounts of text (and, for some models, other data) to learn patterns and generate language.
- Training is the process in which model parameters are adjusted using data.
- Inference is using an already-trained model to produce an output for a new input.
- A pre-trained model has already undergone an initial training process and can be used as a starting point for an application.
- Benefits include saving development time and avoiding the need to train a large model from scratch.
- Limitations include hallucinations, bias, privacy concerns, cost, context-window limits and knowledge cut-offs.
