## Key concepts covered
- Provider: the organization/company offering AI models or services.
- Model: the trained system that processes inputs and produces outputs.
- Application: software that uses a model to provide a user-facing feature.
- Multimodal AI: AI that can work with more than one type of input/output, such as text, images, audio or video.
- Open-weight model: a model whose trained weights are made available under stated terms; check licence, hardware and deployment requirements.
- Model evaluation: testing models against relevant criteria such as accuracy, speed, cost, context length, capabilities and privacy.
